QUEENS — TIENDA ONLINE DEMO

Contenido
- index.html  -> estructura/HTML de la tienda
- style.css   -> estilos y responsive
- script.js   -> productos, buscador, filtros, carrusel y carrito
- assets/logo.png -> logo generado para Queens

Cómo probar
1. Abrí index.html en Chrome/Edge/Firefox.
2. El carrito usa localStorage, por lo que conserva los productos en el navegador.
3. Los productos son ficticios para preview y el botón de checkout está preparado como punto de integración.

ETIQUETAS EN EL CÓDIGO
Encontrarás comentarios con el formato:
===== SECCIÓN =====
para localizar rápidamente header, buscador, carrusel, productos, filtros, carrito, modal y footer.
